A deterministic Python/PIL renderer that draws one uncaptioned open passport spread for the Republic of Vessalia, a country that does not exist: a data page with a portrait and an ICAO-checksummed machine-readable zone, and a facing page of arrival and departure stamps from its invented neighbours — every date, name and number drawn from a single source of truth so the document never contradicts itself.

## Run it

```sh
python3 main.py
```
